# Baiden Creatives

Website for Baiden Creatives, a web design, web development and graphic design studio in East Legon, Accra, Ghana.

Live: https://www.baidencreatives.org (baidencreatives.org redirects here)

Static site (HTML, CSS, vanilla JS). Vercel serves the committed files directly and deploys from `main`.

## Pages
`/` home, `/about`, `/work`, `/pricing`, `/start-a-project`, plus `404.html`.

## Editing
The HTML pages, `sitemap.xml`, `sitemap.xsl` and `robots.txt` are generated by one script so the header, footer and SEO data stay identical on every page:

```
python3 tools/build.py
```

Edit content in `tools/build.py` (projects, services, plans, FAQs, social links), run it, then commit the generated files. Styles are in `style.css` and behaviour in `script.js`.

## Other files
- `assets/`: logos, icons, share image
- `site.webmanifest`, `llms.txt`, `humans.txt`, `vercel.json`: PWA, AI-readable summary, credits and hosting config
