# Baiden Creatives

Website for Baiden Creatives, a web design, web development and graphic design studio in East Legon, Accra, Ghana.

Live: https://baiden-creatives.vercel.app

Static site (HTML, CSS, vanilla JS). No build step. Deploys automatically from `main` on Vercel.

- `index.html`, `style.css`, `script.js`: the site
- `assets/`: logo, icons, share image
- `site.webmanifest`, `robots.txt`, `sitemap.xml`, `llms.txt`, `vercel.json`: SEO, PWA and hosting config
